# 主神空间 · 状态面板

给 SillyTavern（酒馆）+ 酒馆助手用的状态块渲染器。把 AI 每楼末尾那堆 `scene:` / `p1:` / `cr1:` 文本，渲染成一张作战指挥台样式的 HUD 卡片。

**装一次就好。以后面板更新，你刷新页面就是最新版，不用再导入任何文件。**

---

## 一、安装（三步，约 1 分钟）

> 前提：SillyTavern 里已经装好「酒馆助手」扩展（TavernHelper）。没有的话先装扩展，再回来做这三步。

### 1. 下载引导脚本

点这里 → 页面右上角 **Download raw file**（⬇ 图标）：
**https://github.com/FlusAyr/tw-panel/blob/main/dist/loader-script.json**

得到一个 `loader-script.json` 文件。右键另存为也可以。

### 2. 导入到酒馆助手

打开 SillyTavern → **酒馆助手 → 脚本 → 导入** → 选刚才那个 `loader-script.json` → 确认它处于**启用**状态。

### 3. 刷新页面

刷新后打开任意有状态块的聊天，看到下面两样就成功了：

- 消息里出现 HUD 卡片（指令栏 / 双栏 / 日志 / 选项键）
- 卡片右下角有版本水印，如 `v3.8`

控制台会打一行 `[tw-loader] 面板已启动 v3.8.0`。

---

## 二、两件容易做错的事

**① 不要同时装旧的面板脚本。**
如果你以前手动导入过 `tw-card 状态面板 vX.X`，请到酒馆助手 → 脚本里把它**停用或删除**。两份同时启用会互相抢渲染，表现为面板闪烁或出现两份，引导脚本也会在右下角弹黄字提醒。

**② 以后不要再来下载。**
面板更新由引导脚本自动完成：每次打开页面先读本地缓存秒开，后台比对版本，有新版本才下载并提示「已更新，刷新生效」。断网或 CDN 不通时照常渲染上一版，不影响使用。

> 想手动检查：控制台执行 `twPanelCheck()`；查当前版本：`twPanelVersion()`。

## 四、出问题了

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 面板完全不出现，右下角红字「无法连接更新源，且本地无缓存」 | 首次安装时没网，或仓库地址被改坏 | 联网后刷新；或在 [`dist/`](dist/) 里下载 `panel-script-v3.8.json` 临时导入 |
| 面板闪烁 / 出现两份 | 旧的手动脚本还开着 | 只保留引导脚本，其余面板脚本停用 |
| 一直提示「已更新，刷新生效」但版本没变 | 浏览器存储写不进去（无痕模式 / 空间满） | 换普通窗口；控制台看 `localStorage['tw-card:meta']` |
| 别人的新面板，我这边还是旧版 | 版本清单有缓存延迟（raw 约 5 分钟，CDN 最长 12 小时） | 等一会再刷，或执行 `twPanelCheck()` |
