## Part 1 · 安装渲染器（所有人，约 1 分钟）

> 前提：SillyTavern 里已经装好「酒馆助手」扩展（TavernHelper）。没有的话先装扩展。

### 1. 下载引导脚本

点这里 → 页面右上角 **Download raw file**（⬇ 图标）：
**https://github.com/FlusAyr/tw-panel/blob/main/dist/loader-script.json**

得到一个 `loader-script.json` 文件。右键另存为也可以。

### 2. 导入到酒馆助手

打开 SillyTavern → **酒馆助手 → 脚本 → 导入** → 选刚才那个 `loader-script.json` → 确认它处于**启用**状态。

### 3. 刷新页面

刷新后打开任意带状态块的消息，看到下面两样就成功了：

- 消息里出现 HUD 卡片（指令栏 / 双栏 / 日志 / 选项键）
- 卡片右下角有版本水印，如 `v3.34.0`

控制台会打一行 `[tw-boot] 面板已启动 v3.34.0`。

**装完就不用再管了。** 以后面板更新由引导脚本自动完成：每次打开页面先读本地缓存秒开，后台比对版本，有新版本才下载并提示「已更新，刷新生效」。断网或 CDN 不通时照常渲染上一版。

> 手动检查更新：控制台执行 `twPanelCheck()`；查当前版本：`twPanelVersion()`。

## Part 2 · 还原完整环境（主持人 / 自建者）

只有需要"让 AI 自己按规则输出状态块、并把数据存进数据库"的人才要做这部分。做之前请先完成 Part 1。

一套完整环境是三层：酒馆本体跑起来 → 插件提供数据能力 → 我们提供的世界书和模板定义规则。

### 2.1 谁提供什么

| 要装的东西 | 提供方 | 从哪拿 |
|---|---|---|
| SillyTavern 本体 | SillyTavern 官方 | https://github.com/SillyTavern/SillyTavern （文档 https://docs.sillytavern.app/ ） |
| 酒馆助手扩展（TavernHelper） | 扩展作者 | 酒馆 → 扩展 → 安装扩展，按其原贴/社群置顶的地址填 |
| **数据库插件（龙血玄黄·数据库）** | **AlbusKen** | **必须去作者处下载** → https://github.com/AlbusKen/shujuku 根目录下的 `酒馆助手脚本-龙血玄黄·数据库.json` |
| 世界书 ×2（无限恐怖 / 跑团通用） | 本仓库 | [`content/worldbook/`](content/worldbook/) |
| 数据库模板（12 表） | 本仓库 | [`content/database/`](content/database/) |
| 状态面板 | 本仓库 | 见 [Part 1](#part-1--安装渲染器所有人约-1-分钟) |
| 自定义条目（幸运 / 魔药体系） | 本仓库 | [`content/entries/`](content/entries/) |

> **本仓库不存放、不转发任何第三方插件文件。** 数据库插件由作者持续更新、体积接近 10 MB，请一律从作者处获取最新版。我们只提供与之配套的**模板**（表结构是我们自己写的）和规则内容。

### 2.2 安装顺序（照这个顺序，别跳）

1. **装 SillyTavern**，确认能正常对话。
2. **装酒馆助手扩展**，确认酒馆里出现「脚本」页面。
3. **装数据库插件**：从作者处下载 → 酒馆助手 → 脚本 → 导入 → 启用 → 刷新，确认能看到插件自己的面板。
4. **导入两本世界书**：酒馆 → 世界书 → 导入 `content/worldbook/` 下两个 json，然后设为全局启用或绑定到角色卡。
5. **导入数据库模板**：在数据库插件里导入 `content/database/无限恐怖数据库模板_主神空间深度版.json`，确认建出 12 张表（含「称号登记表」「随从与机装表」）。
6. **装渲染器**：回到 [Part 1](#part-1--安装渲染器所有人约-1-分钟) 三步。这一步和前面几步互不影响，先装哪个都行。
7. **开一个新聊天**，发一楼，看 AI 是否输出状态块、面板是否渲染。

顺序上唯一的硬要求是：**插件必须先于模板**（模板是往插件里导的）。世界书要早于开聊，否则 AI 不知道状态块格式。

### 2.3 装完自检

| 检查 | 通过的样子 |
|---|---|
| 世界书 | 世界书列表里两本都是启用状态，条目数分别为 30 和 19 |
| 数据库 | 插件里能看到 12 张表；「纪要」表是 6 列、编码 `AM0001` 起（这一列结构不能变，记忆追回依赖它） |
| AI 输出 | 让 AI 输出一楼，末尾应出现 `scene:` / `p1:` / `cr1:` 等键行 |
| 渲染 | 上述键行被渲染成 HUD 卡片，右下角有版本水印 |

四处都对上，环境就还原完了。剩下的玩法看世界书和 `content/docs/`。

## 附一 · 两件容易做错的事

**① 不要同时装旧的面板脚本。**
如果你以前手动导入过 `tw-card 状态面板 vX.X`，请到酒馆助手 → 脚本里把它**停用或删除**。两份同时启用会互相抢渲染，表现为面板闪烁或出现两份，引导脚本也会在右下角弹黄字提醒。

**② 装完 Part 1 就不要再来下载面板。**
`dist/` 里的文件只在首次安装、或离线降级时用。日常更新是自动的，重复导入只会制造冲突。

## 附二 · 出问题了

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 面板完全不出现，右下角红字「无法连接更新源，且本地无缓存」 | 首次安装时没网，或仓库地址被改坏 | 联网后刷新；或在 [`dist/`](dist/) 里下载 `panel-script-v3.13.0.json` 临时导入 |
| 面板闪烁 / 出现两份 | 旧的手动脚本还开着 | 只保留引导脚本，其余面板脚本停用 |
| 一直提示「已更新，刷新生效」但版本没变 | 浏览器存储写不进去（无痕模式 / 空间满） | 换普通窗口；控制台看 `localStorage['tw-card:meta']` |
| 别人的新面板，我这边还是旧版 | 版本清单有缓存延迟（raw 约 5 分钟，CDN 最长 12 小时） | 等一会再刷，或执行 `twPanelCheck()` |
| 装好了但面板一直是空的 | 消息里没有状态块，或格式不对 | 这是 Part 2 的事：检查世界书是否启用、AI 是否按格式输出 |
| 数据库插件装不上 / 报错 | 插件版本与酒馆助手不匹配 | 去作者仓库看最新说明，我们无法代为排查第三方插件 |

## 附三 · 让 AI 助手替你装

懒得一步步点？把下面这份手册整个丢给任意 AI 助手（Claude Code / Cursor / 带终端的模型都行），它会从装 SillyTavern 开始往下做，遇到必须在浏览器点的步骤会停下来指导你。

- **[AGENT_DEPLOY.md](AGENT_DEPLOY.md)** —— 给 AI 的执行手册：环境检查、clone、装扩展、放世界书、四次手工点击的精确路径、总验收清单、失败处理表
- **[deploy.py](deploy.py)** —— 一键脚本，把文件层的活全干完，跑完打印剩下的手工步骤

```bash
python deploy.py --dir "D:/st-env"   # 从零装（约 20 分钟，含 npm install）
python deploy.py --skip-st           # 已有酒馆，只放世界书和导入包
python deploy.py --dry-run           # 先看会执行什么，不动磁盘
```

分工说明：脚本能干的是**文件系统与命令行**（clone、npm install、下载世界书、建目录）；**必须在浏览器里点的四处**是「导入数据库插件」「导入数据库模板」「导入渲染器」「启用世界书」——这些数据存在浏览器端，命令行写不进去，AI 也不该用注入存储的方式绕过。
