# 内容下载区

主神空间跑团系统的全部成品文件。按顺序装即可，不需要读源码。

> 面板最新版 **v3.8.0**　｜　世界书 **无限恐怖 v2 / 跑团用 v4**　｜　数据库模板 **10 表深度版**

## 一、安装顺序（新玩家）

| 步 | 做什么 | 用哪个文件 |
|---|---|---|
| 1 | 酒馆助手 → 世界书 → 导入（两个都要） | `worldbook/无限恐怖_v2_联机版_AI精简.json`<br>`worldbook/跑团用世界书_v4_联机版_AI精简.json` |
| 2 | 酒馆助手 → 脚本 → 导入**一次** | `panel/tw-card 自动更新引导_导入包.json` |
| 3 | 数据库插件：先装插件本体，再导入模板 | `database/插件入口_数据库本体.json`<br>`database/无限恐怖数据库模板_主神空间深度版.json` |
| 4 | 角色卡挂世界书、启用脚本、开新聊天 | — |

第 2 步完成后**永远不用再导入面板**：引导脚本会在每次打开页面时检查 `version.json`，有新版本自动下载并缓存，刷新即生效。想手动更新就导入 `panel/tw-card 状态面板 v3.8_手动导入版.json`（那份不会自动更新）。
**注意：旧的“tw-card 状态面板”脚本必须停用**，两份同时跑会抢渲染。

## 三、常见问题

- **面板没出来**：确认引导脚本已启用、旧脚本已停用；控制台看 `[tw-loader] 面板已启动 vX`，或执行 `twPanelCheck()` 手动检查。
- **玩家属性没记进纪要**：纪要正文里必须带属性快照（全局表【纪要补充要求】已约束），不要去改纪要表的列结构。
- **更新了但自己还是旧版**：刷新页面；仍不行则 `twPanelCheck()` 看日志，jsDelivr 对新 tag 可能有几分钟延迟。
- **想改面板**：看仓库根目录 README 的“日常发版流程”，改 `panel.js` → `python build.py` → 打新 tag。
