# 内容下载区

> 面板（渲染器）不在这里。它在仓库根的 [`dist/`](../dist/)，安装步骤见 [仓库首页](../README.md)。
> 本目录只放世界书、数据库模板、自定义条目和文档。

主神空间跑团系统的全部成品文件。按顺序装即可，不需要读源码。

> 面板最新版 **v3.20.0**　｜　世界书 **无限恐怖 v2 / 跑团用 v4**　｜　数据库模板 **10 表深度版**

## 一、装什么、什么顺序

> 酒馆本体、酒馆助手扩展、数据库插件这三样不属于本仓库，完整环境还原见[仓库首页 Part 2](../README.md#part-2--还原完整环境主持人--自建者)。
> **只想要渲染器（不自己跑团）的人不用看本页**，去首页 [Part 1](../README.md#part-1--安装渲染器所有人约-1-分钟) 三步即可。

| 步 | 装什么 | 文件 |
|---|---|---|
| 1 | 两本世界书（都要） | `worldbook/无限恐怖_v2_联机版_AI精简.json`<br>`worldbook/跑团用世界书_v4_联机版_AI精简.json` |
| 2 | 数据库模板（插件本体去作者处下载） | `database/无限恐怖数据库模板_主神空间深度版.json` |
| 3 | 状态面板（只导入一次，之后自动更新） | [`../dist/loader-script.json`](../dist/loader-script.json) |
| 4 | 自定义条目（按需，玩什么装什么） | `entries/` 下挑 |

第 3 步完成后**永远不用再导入面板**：引导脚本每次打开页面比对版本，有新版本自动下载缓存，刷新即生效。离线玩家可改用 [`../dist/`](../dist/) 下最新的 `panel-script-v<版本>.json`（手动版，不自动更新）。
**注意：旧的「tw-card 状态面板」脚本必须停用**，两份同时跑会抢渲染。

## 三、常见问题

- **面板没出来**：确认引导脚本已启用、旧脚本已停用；控制台看 `[tw-loader] 面板已启动 vX`，或执行 `twPanelCheck()` 手动检查。
- **玩家属性没记进纪要**：纪要正文里必须带属性快照（全局表【纪要补充要求】已约束），不要去改纪要表的列结构。
- **更新了但自己还是旧版**：刷新页面；仍不行则 `twPanelCheck()` 看日志，jsDelivr 对新 tag 可能有几分钟延迟。
- **想改面板**：看仓库根目录 README 的“日常发版流程”，改 `panel.js` → `python build.py` → 打新 tag。
