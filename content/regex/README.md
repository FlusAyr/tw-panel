# content/regex/ 正则脚本

> SillyTavern **原生正则**（扩展菜单 → 正则），不需要酒馆助手 / JS-Slash-Runner。两个文件内容原样入库，未改一个字节。

两个脚本各治一件事：AI 回复里的 `（第N楼）` 水印（界面噪点）；楼龄 ≥10 的老消息整条置空（省 token）。

| 文件 | 作用 |
|---|---|
| `13_去楼层数_仅显示.json` | 只在界面上删掉 `（第N楼）` 括注；发给模型的提示词不动 |
| `隐藏远楼层消息_超10楼不发送.json` | 楼龄 ≥10 的消息整条置空：界面不显示，**也不发给模型** |

## 装法

扩展菜单（拼图图标）→ 正则（Regex）→ 点「导入」→ 弹窗选 **Global Scripts（全局）** → 两个 json 各导一次。

导出目标默认就是 Global Scripts。**选成 Scoped Scripts（随角色卡）只在当前角色生效**——看着像装好了，换个角色就没效果。

## 装完怎么验

1. 正则面板里能看到两条脚本名（`13去楼层数`、`[隐藏][不发送]远楼层消息`），且都没有被禁用。
2. 随便生成一条回复，界面上不该出现 `（第N楼）`。
3. 楼数超过 10 后，往上翻老消息应显示为空。

## 三个坑

- **`13去楼层数` 只改显示。** 想让模型也看不到，得再勾「仅格式提示词」——但那样模型也失去自己的楼层标注，多数剧本不建议。
- **`隐藏远楼层消息` 会让老剧情从上下文消失。** 依赖长记忆的剧本别装；装了又抱怨「AI 忘了前面」就是这个原因。
- **深度按「距最新一条多远」算**，不是按楼层编号：`depth 0` = 最新一条，数字越大越旧，`minDepth 10` = 跳过最近 10 条以外的全部。

## 字段语义（已在 SillyTavern 源码核过）

```
placement    1 用户输入 / 2 AI 输出 / 3 斜杠命令 / 5 世界书      （0 是 MD_DISPLAY，已废弃）
markdownOnly 「仅格式显示」——只影响界面，不影响发给模型的提示词
promptOnly   「仅格式提示词」——只影响提示词，不影响界面
两项都勾     显示与提示词都处理（第二个脚本就是这种）
minDepth     depth < minDepth 时跳过；maxDepth 反之。depth 0 = 最新一条，数字越大越旧
runOnEdit    编辑消息时是否重跑
```

两个脚本的实际取值：

| 字段 | `13_去楼层数_仅显示.json` | `隐藏远楼层消息_超10楼不发送.json` |
|---|---|---|
| `findRegex` | `/（第.*?楼）/gs` | `/.*/s` |
| `replaceString` | 空 | 空 |
| `placement` | `[2]`（AI 输出） | `[1, 2]`（用户输入 + AI 输出） |
| `markdownOnly` / `promptOnly` | `true` / `false` | `true` / `true` |
| `minDepth` / `maxDepth` | `null` / `null` | `10` / `null` |
